Box Shadow Parser

An interactive demo of the JavaScript Box Shadow Parser - paste any CSS box-shadow value, or click an example below, to see it broken down into structured layer objects. Each layer shows the offsets, blur, spread, inset flag, original color, alpha, and a resolved 6-digit hex. Multi-layer shadows, all color formats, and full box-shadow: ...; declarations are supported.

Full documentation, install instructions, and the complete API: html-code-generator.com/javascript/box-shadow-parser
